# 收集感音效第二轮

2026-11-11 用户反馈：“还差一点，想要收集的感觉”。第一轮未被接受，不沿用按钮/通知音作为定稿。

本轮尝试设计“靠近 → 接住 → 落定”的短动作。三个方向仍是试听草案，名字表达意图，不代表已由代理听取或用户认可。

- A 吸进去：反向短气流放慢 + 降低音高的拾取 pop，0.38 秒。
- B 放进小袋：实际道具硬币袋落木桌录音，去除开头空白、降低高频、短尾，0.46 秒。来源动作是袋子落桌，不冒称录到了物品放入袋子。
- C 归拢收好：两个低音量拾取纹理 + 更低的单次落点，0.36 秒。是一次完整反馈，不是每个文件各响一次。

视觉保持用户已选 C 轻弹 + B 勾号。未改动原生 App，未安装日用版，没有自动播放或 computer use。

## 素材与可复现处理

四个 Freesound 来源均由 sound skill 的 CC0 过滤查询获得，以同一脚本下载 HQ MP3 预览。作者、来源 URL、许可、下载数和评分快照见 sources.json，候选通过 make_candidates.py 生成。测量见 measurements.json、processing.json。

- 585257 lesaucisson: swoosh-1.mp3；17,095 下载，4.7 / 219 票。来源为短 swoosh。
- 665183 el_boss: Item or Material Pickup Pop 1 of 3；3,004 下载，4.8 / 70 票。作者说明用于种田/制作游戏的物品拾取声音。
- 563465 nicholasdaryl: ItemPickup.wav；2,498 下载，4.9 / 40 票。作者说明为物品拾取。
- 575583 The_Frisbee_of_Peace: Pouch ofGold Coins Place Down on Wood.wav；119 下载，暂无足够评分。作者说明为约 100 枚锌制道具币的袋子放到木桌上，用 Zoom H1N 录制。按来源动作匹配选入，未把低下载量当作高信心。

数值为本次查询快照，网页缓存可能不同。前两个是使用最高下载量且题材匹配的来源；排除了爆炸、拳击、玻璃破碎、机器启动等虽命中关键词但不符合场景的素材。

输出 44.1kHz / 16bit mono WAV，最强 40ms RMS 目标 -25dBFS，峰值上限 -12dBFS。主观响度与音色尚需用户试听。试听输出保留短淡出，未使用长混响。
