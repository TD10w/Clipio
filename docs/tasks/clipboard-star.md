# 后续规划：剪贴板 Star 收藏

状态：设计讨论中；部分规则已确认，尚未实施。

来源：用户于 2026-11-11 口述，要求“之后聊一下怎么设计，先存一下”，随后指定存到 Clipio 的后续规划里。

## 需求

给剪贴板内容标记 Star 后保存起来，方便以后找到并直接粘贴、反复使用。

典型用途：个人网站、LinkedIn、社交媒体及其他常用链接。

## 已确认（2026-11-11，grill-with-docs 第一轮）

- 收藏长期保留，直到用户主动取消收藏或删除；普通清空历史不影响收藏。
- 保留剪贴板已有的内容能力，图片明确可收藏，不限定为链接与文字。
- 沿用现有 Clipio 的复制、粘贴操作，不新增一套取用方式。

来源：用户原话“一，是，二，图片应该可以保留吧，就是clipboard的功能。三，是的。”

## 待后续讨论

- Star 的入口，以及之后如何找到收藏并粘贴。
- 与现有剪贴板 Pin 的关系，以及已有 Pin 如何衔接。
- 取消收藏、主动删除、清空全部等边界；文件引用是否另有保留要求。
