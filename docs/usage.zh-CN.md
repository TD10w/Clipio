## 安装与更新

使用 README 中的 DMG 下载入口。GitHub 自动生成的“Source code”压缩包是源码，不是安装包。使用下载版不需要 Xcode 或终端命令。版本发布页也提供 ZIP 和校验和。

Clipio 在菜单栏运行，没有普通应用那样的 Dock 主窗口。官方下载版可在设置 → 通用 → 检查更新中更新；也可以先退出应用，再下载新版本替换。如果 macOS 拒绝打开，请确认系统为 macOS 14 或更高版本，从本仓库重新下载，并反馈准确报错，无需全局关闭 Gatekeeper。

从 2.6.1 升级后，打开剪贴板的快捷键为 **Shift + Command + V**，**Shift + Command + C** 打开收集区。剪贴板历史会保留，两个快捷键均可在设置中修改。

## 剪贴板

在其他应用里复制内容，再打开卡片栏。直接输入文字可搜索当前卡片栏，悬停查看预览。默认按 Return 复制选中内容，再到目标应用按 Command + V 粘贴；开启“默认粘贴”会改变这一行为。

设置中可调整外观、透明度、历史条数、忽略的应用和搜索方式。透明度滑条向左更通透，向右更磨砂。默认历史上限为 200 条，收藏项不随普通历史淘汰。

首次打开的英文上手指南，可从齿轮菜单 → Getting Started 或设置 → General 重新查看。

## 文件收集区

- 开始拖动文件、文件夹或浏览器图片，屏幕上方会出现玻璃小胶囊 Drop Zone。直接放入即可；停留约半秒会展开完整收集区。
- 普通项目拖到 Finder 会移动原文件。先 Pin 再拖出会复制，并保留收集项。
- 一次放入的多个文件会成为一个 Stack。点击展开，点 ‹ 收起。收起时拖出、Pin 作用于整组，展开后可单独操作。
- 退出后内容仍保留。搜索按文件名匹配，搜到 Stack 中任意文件时会显示整组。
- 普通本地文件保存引用，不另外复制；浏览器图片和支持导入的应用私有目录文件保存在 Clipio 自己的本机数据中，保留来源文件。移除或清空收集项不会删除原文件。

应用私有目录文件的副本上限为每项 64 MiB，默认总预算为 128 MiB。更大的文件，或只能在来源应用内生成的文件，请先保存到 Finder 文件夹，再拖入收集区。

## 自动粘贴权限

Option + Return 自动粘贴需要在**系统设置 → 隐私与安全性 → 辅助功能**中允许 Clipio。复制卡片内容、再手动按 Command + V 不需要此权限。

更新或替换本地构建后，如果自动粘贴失效，请重新检查 Clipio 的辅助功能授权。

## 敏感内容

历史记录保存在本机，没有云同步或使用分析，也没有应用层数据库加密。Clipio 会跳过支持的隐私、临时剪贴板标记，但无法识别所有以普通文字复制的密码。可按需忽略相关应用或暂停记录。

清空历史和清空系统剪贴板是不同设置。重要内容请另留副本。反馈问题时，请勿上传剪贴板数据库、完整设置、密码、令牌或未经脱敏的录屏。

## 测试版限制

另一台 Mac 的安装体验和完整界面清单仍待独立验证。收集区跨磁盘移动、系统重启后的行为、跨显示器拖拽尚未验证。部分新界面文字和辅助功能提示目前仅有英文。拖拽表现可能受目标应用影响。

技术跟进和验证记录见[开发文档](development.md)。
