## English

- Use the native app-icon format so the banana-horse artwork fills the macOS icon enclosure.
- Fix extra background padding that macOS 26/27 applies to the legacy icon representation.
- Include the English Getting Started guide and the menu-bar entry fix.

Download **Clipio-2.7.5-beta.1.dmg**, open it and drag Clipio into Applications. Quit the running copy before replacing it. A ZIP and SHA-256 sidecars are also available.

This is a public beta with manual updates. The guide uses English in every system language. Independent installation on another Mac, cross-disk file moves and the complete workflow after a system restart remain unverified.
