# Clipio 2.9.0

Clipio's first release out of beta.

- **A hands-on Getting Started guide.** Pick the shortcut you want (Shift-Command-V is recommended), copy, open and paste once for real, and switch to Collection with its own shortcut. Clipio lives in the menu bar with no main window, so the guide also shows where to find it, and how to get back in when a crowded menu bar or the notch hides the icon. Launch at login is on by default and can be turned off on the last step.
- **Automatic paste you can actually turn on.** The guide offers to let Clipio paste for you: press Return on a card and it lands where you were typing. Fixed: Clipio could not add itself to System Settings → Privacy & Security → Accessibility, so there was nothing to switch on.
- **Paste and typing now work in Chrome, WeChat and other Chromium/Electron apps.** After the shelf closed, these apps did not get keyboard focus back, so automatic paste and the next keystrokes were lost.
- If you close the guide part-way, it appears once more on the next launch. You can always reopen it from the gear menu → Getting Started.

## 中文说明

- **新的上手引导，可以边学边练。** 先选快捷键（推荐 Shift-Command-V），再亲手完成一次复制、打开、粘贴，并学会用收集区自己的快捷键打开它。Clipio 只在菜单栏运行、没有主窗口，所以引导也会告诉你图标在哪里；菜单栏太挤或被刘海挡住时，还能怎么打开它。开机自动启动默认打开，可以在最后一步关掉。
- **自动粘贴终于能打开了。** 引导里可以允许 Clipio 帮你粘贴：在卡片上按回车，内容会直接贴到你正在输入的位置。修正了 Clipio 无法出现在「系统设置 → 隐私与安全性 → 辅助功能」列表里、导致没有开关可开的问题。
- **在 Chrome、微信等基于 Chromium/Electron 的 App 里，粘贴和输入恢复正常。** 以前面板关闭后，这些 App 拿不回键盘焦点，自动粘贴和随后输入的内容都会丢失。
- 如果中途关掉引导，下次打开 Clipio 时还会再出现一次；随时可以从齿轮菜单 → Getting Started 重新查看。

Requires macOS 14 or later. Apple silicon and Intel.
