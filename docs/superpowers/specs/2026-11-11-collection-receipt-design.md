# 收入成功反馈设计

用户已在对话确认视觉 C 的轻弹 + B 的勾号，并选择第二轮声音 A（2026-11-11：“A it is”）。本文件记录已批准的组合，后续由代理完成技术实现。

- 意图：让用户感到物品被接住、收进来了。
- 视觉：沿用顶部玻璃小胶囊；轻微放大回弹一次，托盘短暂变成勾号，约 1 秒后收起/恢复拖入状态。不显示数量或成功文字，不改日用版。
- 声音：使用试听原文件 `sound-study-v2/candidates/01-drawn-in.wav`，长 0.38 秒。声音与轻弹、勾号同步开始。声音只代表实际保存成功。
- 单次拖入多文件等待本批处理结束，只反馈一次；普通 drop、收集区 drop、file promises 共用完成统计。空批次、取消、全失败和重复项目不反馈。
- 技术裁定：部分成功但部分失败时不发完整成功反馈，保留现有错误说明，避免勾号掩盖失败。不同并发批次独立计数；极短时间内完成的多批在界面上可合并为一次回应，避免连续叠响。
- 快速连续收入可重触发动画并延长展示；旧的收起回调不能收掉新的反馈。声音不循环、不自动在启动/恢复历史时播放。
- 不抢焦点，不操作鼠标，反馈层可穿透点击；开始新的拖动时恢复接收能力。沿用 Reduce Motion，关闭动态效果时静态勾号仍可见。
- 素材为 Freesound CC0 的加工组合。保留来源记录，不改变既有 Write/Knock 复制声音。
