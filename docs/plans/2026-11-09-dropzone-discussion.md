# 文件暂存讨论记录

当前处于范围讨论阶段，以下记录来自 2026-11-09 创始人访谈。

## 已确认

- 收集区位于屏幕刘海下方、当前剪贴板面板出现的位置。
- 拖动内容时，上方出现可展开的接收区域，左右两个板块分别用于拖出后消失和拖出后保留。
- 首版收集内容包括文件和网页图片。网页图片收集后需要能作为图片拖到其他应用。
- 收集区收起后，刘海旁显示小图标和内容数量。点击该入口可再次展开左右两个板块，取用内容。创始人明确回答“可以的”。
- 已收集的内容拖出途中取消时仍保留。只有目标应用成功接收后，“拖出后消失”板块中的相应条目才移除。创始人明确回答“好”。
- 两个板块中尚未移除的内容，在退出 Clipio 或重启电脑后继续保留。创始人对重启保留问题回答“yes”。
- 本地文件引用原件。原件修改后，拖出最新内容；原件删除后，条目无法使用。网页图片保存在本地，供后续作为图片拖出。创始人对整套规则回答“好”。详见 [文件保存决策](../adr/0001-collected-file-storage.md)。
- 原文件移动后尽量跟随，找不到或已删除的条目标记“文件不可用”，由用户移除。
- 首版支持多个文件或文件夹拖入，并支持多选批量拖出。
- 支持单项移除和清空，清空前确认。本地原件保留，收集的网页图片清理后释放空间。清空的具体作用范围取决于收集区组织方案。

## 待确认

- 创始人提出改用单一收集区，通过 Pin 决定拖出后保留，替代原先两个板块；当前正在讨论，尚未选定。
- 剪贴板与收集区的切换方式。
