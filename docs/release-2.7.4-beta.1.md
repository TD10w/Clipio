# Clipio 2.7.4-beta.1 — App icon

App version 2.7.4, build 66. macOS 14+, Apple Silicon and Intel.

## 简体中文

- 更新香蕉小马应用图标，放大主体、收紧外围留白，并使用透明外缘，让 Finder、启动器中的图标更饱满。
- 包含 2.7.3 的三页英文上手指南和菜单栏入口遮挡修复。

下载 **Clipio-2.7.4-beta.1.dmg**，打开后将 Clipio 拖入「应用程序」。更新前退出已运行的 Clipio。也提供 ZIP 和 SHA-256 校验文件。

## English

- Update the banana-horse app icon with larger artwork, tighter padding and transparent outer edges so it appears fuller in Finder and app launchers.
- Include the three-page English Getting Started guide and the menu-bar entry fix from 2.7.3.

Download **Clipio-2.7.4-beta.1.dmg**, open it and drag Clipio into Applications. Quit the running copy before replacing it. A ZIP and SHA-256 sidecars are also available.

This is a public beta with manual updates. The guide uses English in every system language. Independent installation on another Mac, cross-disk file moves and the complete workflow after a system restart remain unverified.
