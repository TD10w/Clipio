# Clipio 2.9.3

**[Download Clipio 2.9.3 for macOS (.dmg)](https://github.com/TD10w/Clipio/releases/download/v2.9.3/Clipio-2.9.3.dmg)** · **[下载 macOS 安装包](https://github.com/TD10w/Clipio/releases/download/v2.9.3/Clipio-2.9.3.dmg)**

Open the DMG, then drag **Clipio.app** into **Applications**. / 打开 DMG，将 **Clipio.app** 拖入“**应用程序**”。

- **Files dragged from Collection into a website now leave Collection.** Dropping a file onto a web upload area (for example, a photo uploader in your browser) now removes its card from Collection, the same as dropping it anywhere else. Before, the card stayed. Your original file is not changed.

## 中文说明

- **从收集区拖到网页上的文件，现在会从收集区消失。** 把文件拖到网页的上传区（比如浏览器里的图片上传框）后，它在收集区的卡片会被移除，和拖到其他地方一样。之前卡片会一直留着。你的原文件不会被改动。

Requires macOS 14 or later. Apple silicon and Intel.
