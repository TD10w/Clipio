# Clipio 新版本体验反馈

记录日期：2026-11-09。来源：用户亲自体验后的口述验收。状态：待明天调查和修复；以下是体验与期望，不代表原因已经查明或功能已经验收通过。

## 1. Liquid Glass 透明度

用户觉得新版本的透明度与上一版 Liquid Glass 的体验不同。希望透明度能跟随系统，或者允许自己调整。明天先确认系统材质与透明度设置能提供什么，再确定合适的调整方式；当前尚未决定具体方案。

## 2. 拖入入口与唤出体验

将东西拖向 folder／Dropzone 时，入口不够明显；希望入口像在迎接拖入的内容一样，有清楚的视觉反馈。现在移动时感觉不够丝滑，希望拖动过程中界面就能出来，而不是必须把指针移到最上方 menu bar 才出现。具体触发范围和动画需要结合真实拖动体验确定。

## 3. 文件拖出：移动与固定后复制

用户体验到目前像是复制了一份，而不是更换文件位置。期望流程：

1. 在 Finder 将一个文件夹拖入 Clipio Dropzone。
2. 打开 Finder 中另一个文件夹，把该项目从 Dropzone 拖出到那里。
3. 默认结果是原文件夹真正移动到新位置，原位置不再有它。
4. 如果用户将项目 pin（固定），拖出时则保留原位置，相当于复制一份到目标位置。

此前“拖出后消失／保留”描述的是暂存区表现，不能单独证明磁盘上的文件已移动或复制。明天需调查 Finder 拖放操作是否成功、目标与跨磁盘等情况，并验证成功、取消及失败时原文件和暂存项目的状态，避免丢失文件。网页图片的处理方式不应直接假设与本地文件相同，待结合原有设计确认。

## 明天验收重点

- 实机比较系统外观及透明度设置下的面板效果，并确认可否提供用户调整。
- 从 Finder 拖动时，观察入口何时出现、反馈是否明显、移动和展开是否顺滑。
- 使用测试文件夹核对普通拖出后源和目标位置；固定后核对源文件保留且目标存在副本。
- 测试取消、失败以及不同磁盘上的行为；记录实际结果，再由用户体验验收。
