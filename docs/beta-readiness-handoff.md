# Clipio 项目交接

更新于 2026-11-10。此页汇总当前源码、公开发布包和下一步工作。

## 当前源码

- 主线基准为 `dc0d9f4`，已合并 [PR #1](https://github.com/TD10w/Clipio/pull/1) 的修复及 [PR #2](https://github.com/TD10w/Clipio/pull/2) 的文档与设计比较。当前开发位于 `design/liquid-glass-system-20261109`，新视觉与收集区尚未合入主线。
- 修复了展开动画期间卡片位置缓存失真，导致悬停预览和选中对象不同步的问题。卡片测量和鼠标命中判断使用同一个面板内部坐标空间。
- 卡片现在向辅助功能接口提供选中状态。回归测试会等待目标卡片选中，再执行回车复制和固定操作。
- 自动化使用隔离应用标识、内存数据库和命名测试剪贴板，通过正常的应用重开入口打开面板，并使用独立的临时快捷键。
- 搜索回归使用固定数字样例，避免当前拼音输入法的候选流程影响测试输入。中文输入法交互需要单独验收。

## 本轮验证

验证环境为 macOS 27.2、Xcode 27.2，arm64。证据对应修复提交 `470362b`，随后由 `76d263e` 合入主线。

- 必需的 unsigned Debug 构建通过。
- 85 项单元测试全部通过。
- 选取的 14 项界面回归中，13 项通过、1 项跳过、0 项失败。通过项覆盖图片和文件复制、点击和回车复制、数字快捷键、固定和取消固定、搜索、悬停后切换键盘选择、快捷键打开、应用重开、Escape 关闭和失焦关闭。
- 菜单栏点击专项因 XCTest 无法访问当前会话的菜单栏图标而跳过，仍待人工验收。
- 完整界面测试集、另一台 Mac 安装和公开发布包的完整验收仍待完成。

## 当前工作

2026-11-09 实际体验反馈见[验收反馈](acceptance-feedback-2026-11-09.md)。普通文件应真正移动、固定后复制的要求取代早期预览版的复制语义；11 月 10 日修复分支已实现，真实 Finder 结果仍待验收。

1. 用户已确认 Apple 原生 Liquid Glass、全部系统标准字体，以及原版香蕉装小马图标。设计分支已完成原生字体、语义颜色与共享材质试排。剪贴板和收集区浅深色截图见[评审素材](../Designs/explorations/2026-11-09-liquid-glass/README.md)。用户已否决简化图标，应用继续使用原版。Figma 因组件权限与 Starter 调用上限仅建成框架，可编辑稿待补齐。
2. Dropzone 工作分支 `feature/dropzone-20261109` 的检查点 `f27fac8` 已于 `3dce65d` 接入设计分支。最终为单收集区加 Pin，普通项成功拖出后消失、取消保留、Pin 保留；剩余内容重启保留。本地文件引用原件，网页图片本地保存。⌘⇧V／⌘⇧C 分别打开剪贴板／收集区，Tab 或单图标切换，搜索独立。见[需求记录](plans/2026-11-09-dropzone-discussion.md)和[实现与证据](superpowers/plans/2026-11-09-file-collection.md)。
3. 整合检查发现图片限额验证过晚和批量 Pin 分次保存的问题，已在 `ac20752` 修复。整合后 110 项单元测试、13 项受影响界面回归及规定 unsigned Debug 构建通过。界面初轮出现一项启动失败，单独复跑与整组复跑均通过，保留为测试稳定性记录。
4. 设计分支仍待创始人视觉确认、真实 Finder／Safari／Chrome 拖拽、外部沙箱授权重启及刘海入口定位验收，未安装或发布。

## 11 月 10 日反馈修复

当前修复分支为 `fix/acceptance-feedback-20261110`，基于 PR #3 的 `842e22f`，尚未合并或发布。普通本地项目采用系统移动操作，Pin 项复制；取消、不完整移动和延后完成的处理已加入隔离回归。入口无数字、边缘留白、拖入迎接和“跟随系统／更通透”材质选择已实现。

最新单元回归 120 项通过；原生入口与设置面板已查看。真实 Finder 落放、跨磁盘、系统透明度及刘海／多屏体验不能由这些结果替代。最新界面回归、复核发现与限制见[修复证据](acceptance-evidence-2026-11-10.md)，集中体验见[11 月 10 日验收清单](manual-acceptance-2026-11-10.md)。昨天的人工清单中“拖出后原件保留”是旧预览语义，不适用于新版本的普通本地项目。

独立本地体验包放在当前工作区 `build/人工验收-20261110/Clipio测试版.app`，标识 `com.clipio.app.manualacceptancenov10`；未启动、安装或分发该包。它与昨天的测试版容器分开。该 Debug 包已本地 ad-hoc 签名检查，不是签名公证后的公开安装包。

## 后续质量事项

- 菜单栏真实点击、中文输入法组合输入、浅深色和多显示器体验需要人工验收。
- 数据库加载失败直接退出、部分保存错误被忽略，属于已在代码中确认的恢复能力缺口。磁盘故障场景需要隔离验证。

- 并发安全编译警告和权限说明的英文硬编码仍在后续维护范围。
- 发布前继续检查素材来源和另一台 Mac 的安装与权限流程。
